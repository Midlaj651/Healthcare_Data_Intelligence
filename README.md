The Healthcare Data Intelligence Dashboard is an interactive Power BI project designed to analyze healthcare data and provide insights into patient demographics, hospital billing, insurance providers, medical conditions, medications, admission types, and test results.

This dashboard helps users understand healthcare trends and monitor key performance indicators (KPIs) through interactive visualizations.

## 🎯 Project Objectives
- Analyze total patient records and healthcare billing.
- Understand patient demographics and age distribution.
- Analyze admission types and gender distribution.
- Explore medical conditions and medication patterns.
- Evaluate insurance provider distribution.
- Monitor yearly healthcare trends.
- Analyze patient test results.

## 📊 Key Performance Indicators (KPIs)
